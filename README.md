# ⌨️ TouchKey POS Pro (v1.0.0)

**TouchKey POS Pro** — специализированная экранная сенсорная клавиатура для POS-терминалов, моноблоков и ресторанно-торговых систем (**RPOS, iiko, r_keeper, 1C, Microinvest**).

---

## 🌟 Возможности (Features)

* 🛡 **No Focus Steal:** Не перехватывает фокус у активных кассовых программ (`WS_EX_NOACTIVATE` + `HWND_TOPMOST`).
* 🔢 **Кассовый NumPad:** Огромные кнопки для ввода цен, сумм, количеств (`0-9`, `00`, `.`, `+`, `-`, `Стереть ⌫`, `Очистить C`, `Ввод ↵`).
* 🔤 **Русская и Английская раскладки:** Мгновенный поиск блюд и клиентов по имени.
* 🌐 **Прямая передача Unicode:** Буквы и символы печатаются на 100% правильно независимо от текущего системного языка ввода Windows.
* 🔍 **Масштабирование на лету:** Кнопки `[ А - ]` и `[ А + ]` для адаптации под экраны 15", 17", 21"+.
* 🔘 **Компактная плавающая кнопка:** Программа стартует аккуратной кнопкой `⌨️ Клавиатура` в углу экрана, не загораживая рабочий стол.
* 🚫 **Блокировка системной клавиатуры Windows:** Автоматически предотвращает вылезание стандартной клавиатуры Windows (`TabTip.exe`).

## 🚀 Установка и запуск

### 1. Готовый установщик (.exe)
Запустите `installer_output/TouchKey_POS_Setup.exe`. Он установит программу, создаст ярлык и добавит в автозагрузку.

### 2. Запуск из исходников
```bash
python main.py
```

### 3. Пересборка инсталлятора
```bash
python build_installer_exe.py
```
Или дважды кликните по файлу `Собрать_Инсталлятор.bat`.

## 📁 Структура проекта
```text
touch_pos_keyboard/
├── app_icon.ico              # Фирменная векторная иконка программы
├── app_icon.png              # PNG логотип
├── keyboard_ui.py            # Интерфейс PyQt6 (NumPad, RU, EN, Symbols, темы)
├── win_input.py              # Win32 API движок ввода (ScanCodes, Unicode, Focus)
├── main.py                   # Точка входа, трей и плавающая кнопка
├── build_exe.py              # Сборка автономного .exe через PyInstaller
├── build_installer_exe.py    # Сборка установщика через Inno Setup
├── installer.iss             # Сценарий Inno Setup с автозагрузкой
├── Собрать_Инсталлятор.bat   # Пакетный файл пересборки в 1 клик
├── Обновить_Программу_У_Себя.bat # Пакетный файл синхронизации у себя
└── installer_output/
    └── TouchKey_POS_Setup.exe # Финальный установщик v1.0.0
```
